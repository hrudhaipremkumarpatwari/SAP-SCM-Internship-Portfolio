# Week 1 Submission Description

This report presents a strategic planning and needs-analysis blueprint for a hypothetical ERP implementation at Horizon Foods Ltd., a mid-sized packaged-food manufacturer with two plants and three distribution centres. It explains why the organization may need a shared ERP process by examining assumed problems with separate spreadsheets and departmental systems, including duplicate supplier and product records, repeated order entry, delayed stock visibility, and time-consuming financial reconciliation. These are scenario assumptions for the assignment and are not claimed as measured facts from a real company. The report recommends validating the business case and requirements before selecting a product or committing implementation funding.

The plan uses the six SAP Activate phases—Discover, Prepare, Explore, Realize, Deploy, and Run—as a public methodology reference, then applies them to an indicative 24-week timeline. Each phase includes activities, deliverables, and a decision gate. The scope covers process discovery for finance, procurement, inventory, sales, and production; master-data ownership; integration and reporting needs; testing; change readiness; and post-launch support. It also identifies critical success factors, decision roles, and risks involving scope growth, data quality, excessive customization, user adoption, bilingual communication, security, integration, and cutover. Mitigations include data ownership, fit-to-standard review, end-to-end testing, user practice, and explicit go/no-go criteria.

A dedicated communication section shows how HSK 4 Mandarin vocabulary can support project updates and user guidance. It provides simplified Chinese terms with pinyin and English meanings, bilingual label examples, and a recommendation to have important translations reviewed by a bilingual user. Technical ERP terms remain paired with precise English identifiers so that accessibility does not create ambiguity. A reflection explains why planning, data governance, and language clarity affect adoption and operational control. The report is a learning blueprint based on a hypothetical scenario; it does not claim live SAP configuration, implementation, or realized business benefits.
